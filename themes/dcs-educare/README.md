# DCS Educare OctoberCMS Theme

This theme was converted from the supplied HTTrack/WordPress static export.

## Structure

- `layouts/default.htm` – common theme layout
- `partials/site/head.htm` – shared `<head>` assets from the original site
- `partials/site/header.htm` – common header
- `partials/site/footer.htm` – common footer
- `partials/site/scripts.htm` – common scripts
- `pages/*.htm` – converted static pages with their original URLs
- `assets/wp-content`, `assets/wp-includes`, `assets/wp-admin` – copied static assets

## Notes

This is a static conversion. WordPress dynamic features such as comments, feeds, Contact Form 7 backend submission, WP REST endpoints, and admin/login functions are not converted into OctoberCMS components. The frontend layout and static content/assets are preserved as much as possible.
